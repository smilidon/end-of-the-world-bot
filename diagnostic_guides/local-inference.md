# Optional local connection and Ollama endpoint

Connection refused / ECONNREFUSED indicates a reported connection failure, not
proof that an application is broken. The intended local endpoint might not be
listening, or the selected port may differ. Compare the owner-selected endpoint
with the application's existing status UI. Do not restart or reconfigure services
from this guide. Model inference is optional: deterministic retrieval remains
available without Ollama. No model download is an automatic recovery step.
