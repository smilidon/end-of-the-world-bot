# Destination permissions and storage

Permission denied / EACCES does not establish its cause. A selected folder may
not be writable, or a removable volume may be read-only. Inspect properties using
the file manager. The installer requires a new user-owned folder. Do not broaden
system permissions, change ownership globally or erase an existing installation.

ENOSPC / no space left on device can mean insufficient storage space, a quota or
filesystem metadata exhaustion. Review volume properties and documented limits.
Keep backups and existing files; this guide does not recommend deleting data.
