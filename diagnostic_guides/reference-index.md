# Reference index and SQLite selection

An unable-to-open-database or missing chunks-table message can reflect a missing,
inaccessible or mismatched reference index. An Index exists message can instead
mean the application's intentional overwrite safeguard worked. Compare the exact
error and explicitly selected library with the documented preparation flow.

Preserve the original library and SQLite index. Test preparation in a fresh
disposable folder, not by deleting or rebuilding an active library. Diagnostic
Markdown guides use their own in-memory FTS5 index and never share the main index.
